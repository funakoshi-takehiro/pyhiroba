使い方

基本の操作

コードを実行
Shift+Enter、または ▶ 実行
テキストを確定
Shift+Enter、または Esc
セルを追加
セルの下の ＋ ボタン
セルを削除
セル右上の ✕ ボタン
字下げ
Tab（スペース4つ分）

知っておくと安心

  • 上のセルで作った変数は、下のセルでも使えます
  • エラーは、やさしい日本語のヒントで出ます
  • ノートは上の「ダウンロード」で保存できます
  • 画面下の「入力補助」で、かっこを自動で閉じられます
  • 画面下の「文字」「行間」で、読みやすい大きさに変えられます

使えるライブラリ

import と書くだけで、自動的に読み込まれます（インストールは不要です）。

numpy, pandas, matplotlib, scikit-learn, scipy, sympy,
Pillow, cv2（画像処理）, requests, random, math ...

AIと画面部品（試験公開）

小さな言語モデルを、この画面の中だけで動かせます。入力した文章が外部に送られることはありません。初回だけモデルを受け取るため、時間と通信量がかかります。

from library_hiroba import ai, ui

await ai.load()
print(await ai.ask("日本の四季について、2行で書いて"))

答えの内容が事実と違うことがよくあるため、調べものには使わないでください。

ui を使うと、カードやクイズなどの部品をセルの下に表示できます。ui.form() で入力欄とボタンを出せば、打ち込んだ内容を Python の関数で受け取れます。

ui.form(lambda q: ui.card(q, "答え"), "質問")

Google Colab でも、次の1行を先に実行すれば同じコードが動きます。

%pip install library-hiroba
