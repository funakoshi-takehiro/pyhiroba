SETUP GUIDE

導入ガイド・対応環境

PyHiroba を学校で安心してご利用いただくための、対応環境とネットワークの設定をまとめました。導入をご検討中の先生や、情報担当の先生にもご確認いただける技術情報です。

準備するもの

  • インターネットに接続できるパソコンと、最新のブラウザをご用意ください。専用ソフトのインストールや、Python などの環境構築は必要ありません。
  • アカウント登録やログインは必要ありません。生徒が ID やパスワードを作成する必要もありません。
  • 先生が配布された URL を開くだけで、その場でプログラミングを始められます。

対応ブラウザ・端末

  • Google Chrome / Microsoft Edge / Firefox / Safari でご利用いただけます（Internet Explorer は非対応です）。
  • Python の実行環境（WebAssembly）を利用するため、動作を確認しているのは Chrome・Edge・Firefox は 112 以降、Safari は 16.4 以降（いずれも 2023 年春ごろ以降のリリース）です。多くのブラウザは自動で更新されるため通常はそのままご利用いただけますが、これより古いバージョンでは動作しないことがあります。うまく動作しないときは、ブラウザの更新をお試しください。
  • OS は問いません（Windows / macOS / Chromebook / iPad など）。
  • コードの入力があるため、キーボードのあるパソコンでのご利用を推奨します。スマートフォンなど画面が小さい端末は、授業でのご利用を推奨していません（キーボードを接続したタブレットであればご利用いただけます）。
  • Python の実行環境をブラウザ内に読み込むため、ある程度のメモリを搭載した端末でのご利用を推奨します（空きメモリ 1GB 以上を目安としてください）。

ネットワークの許可設定（フィルタリング／プロキシ）

学校のネットワークでフィルタリングやプロキシをご利用の場合は、次のドメインへの通信を許可してください。このうち、Python の実行環境の配信元である cdn.jsdelivr.net への通信は必須です。

ドメイン用途区分
cdn.jsdelivr.net Python 実行環境（Pyodide）本体の配信 必須
funakoshi-takehiro.github.io PyHiroba サイト本体（このサイト） 必須
fonts.googleapis.com
fonts.gstatic.com		 画面表示に使うフォント（なくても動作します） 任意
script.google.com
drive.google.com
*.googleusercontent.com		 Google Drive で配布された教材を読み込む場合 教材利用時
raw.githubusercontent.com
github.com		 GitHub 上の教材を読み込む場合 教材利用時

※「教材利用時」の行は、先生が Google Drive / GitHub の外部教材を配布される場合にのみ必要です。組み込みの練習問題のみをご利用の場合は、許可の必要はありません。

通信とデータの扱い

生徒が書いたコードや学習内容、個人情報は、一切外部へ送信されません。プログラムはすべて生徒の端末（ブラウザ）の中で実行されます。上記の通信は「Python 実行環境やフォント、教材を受け取る」ための読み込みのみです。

  • 初回のみ、cdn.jsdelivr.net から Python の実行環境（数十 MB 程度）を読み込みます。
  • 2 回目以降は、ブラウザや Service Worker のキャッシュから起動するため動作が軽くなり、通信が不安定な環境でも利用しやすくなります。
  • 安全面の詳しい取り組みは 安心・安全への取り組み をご覧ください。

オフライン・閉域網でのご利用

  • 初回の読み込み時のみ、インターネット接続（上記の cdn.jsdelivr.net）が必要です。
  • 一度読み込めば、以降は同じ端末・同じブラウザであればオフラインでも起動できます。
  • 完全な閉域網の教室では、一度インターネットに接続できる環境で各端末に読み込ませてからご利用いただく運用をおすすめします。

うまく動作しないとき

  • 「実行環境を読み込めませんでした」と表示される場合は、cdn.jsdelivr.net への通信がフィルタリングで止められていないかご確認ください。
  • ブラウザが古い場合は、最新版に更新してからお試しください。
  • 解決しない場合は、下記のお問い合わせフォームからご連絡ください。

お問い合わせ

導入に関するご質問や、うまく動かない場合のご相談は、お問い合わせフォームからお気軽にお寄せください。
